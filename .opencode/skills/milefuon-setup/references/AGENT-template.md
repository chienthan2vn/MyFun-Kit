# Milefuon Operating Protocol

> **Mandatory Read-Before-Act Protocol for AI Agents**
> Every AI agent MUST read the 5 context overview files listed below at the start of EVERY session before reading track files or modifying project code.

---

## 1. Mandatory Read Sequence (Per-Session)

Before performing any action or answering questions, read these 5 overview files in order:

1. `./milefuon/product.md` — Product vision, goals, target users, non-goals
2. `./milefuon/tech-stack.md` — Languages, frameworks, databases, tools, constraints
3. `./milefuon/workflow.md` — Methodology (TDD, coverage target, status markers)
4. `./milefuon/tracks.md` — Index of active, pending, and archived tracks
5. `./milefuon/patterns.md` — Established codebase patterns and architecture conventions

---

## 2. Setup Check

If any of the 5 overview files above do not exist:
- **HALT immediately.**
- Inform the user: *"Project setup missing or corrupted. Please run `milefuon-setup` to bootstrap or repair the context overview files."*

---

## 3. Skill Map & Hand-off Protocol

| Task / Scenario | Skill to Invoke |
|-----------------|-----------------|
| Initialize project or repair overview files | `milefuon-setup` |
| Create a new feature track or bugfix track | `milefuon-newtrack` |
| Implement task-by-task within an active track | `milefuon-implement` |
| Archive completed track, update patterns/tracks | `milefuon-archive` |

---

## 4. Red Flags & Strict Rules

- **Do NOT proceed without reading all 5 overview files.**
- **Do NOT invent architectural patterns** that violate `./milefuon/patterns.md`.
- **Do NOT ignore coverage rules or methodology** specified in `./milefuon/workflow.md`.
- **Do NOT modify files outside active track scope** without updating track plan.
