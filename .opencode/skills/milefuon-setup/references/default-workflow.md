# Workflow — Milefuon

Implementation methodology for all tracks.

## Methodology

- **Approach:** Test-Driven Development (TDD) — Red → Green → Refactor
- **Test coverage target:** >=80%
- **Commit policy:** One commit per task (auto, never push — user controls remote sync)
- **Verification:** Manual verification task appended to each phase (`Task: User Manual Verification for Phase '<Phase Name>'`)

## Status Markers

| Marker | Meaning |
|--------|---------|
| `[ ]` | Pending |
| `[~]` | In Progress |
| `[x]` | Completed |
| `[!]` | Blocked |

## Skill Chain

```
milefuon-setup      → bootstrap project (one-time)
milefuon-newtrack   → create track with discovery gate (per task)
milefuon-implement  → execute plan task-by-task (per track) — TBD
milefuon-archive    → close track, update project files — TBD
```

## TDD Cycle (per task)

1. Write failing test (RED)
2. Run test — expect FAIL
3. Write minimal implementation (GREEN)
4. Run test — expect PASS
5. Refactor while keeping tests green

## Phase Completion Verification Protocol

At the end of each phase, the final task is:

```markdown
- [ ] Task: User Manual Verification for Phase '<Phase Name>' (Protocol in workflow.md)
```

Steps:
1. Run full test suite for the phase
2. Manually verify acceptance criteria for the phase
3. Mark task `[x]` only after both checks pass
