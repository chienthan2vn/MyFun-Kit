**Do NOT read on every session (lazy-read only when relevant):**

| File | When to read |
|------|-------------|

| `milefuon/tracks/<id>/*` | Only when working on that specific track (`spec.md`, `plan.md`, `learnings.md`) |
| `milefuon/archive/*` | Only when explicitly referenced or seeding learnings for a similar track |

**Violation = halt and read.** Do not proceed if any file in the 5-file sequence is missing — run `.opencode/skills/milefuon-setup` first.
